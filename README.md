# Rapporti di sostenibilità Ferrero

Pagina web realizzata per il project work del corso di Informatica per le Aziende Digitali.

Il progetto presenta in forma sintetica le principali informazioni relative alla sostenibilità del Gruppo Ferrero, organizzandole in sezioni dedicate all'azienda, ai quattro pilastri della sostenibilità, ai principali risultati e ai rapporti di sostenibilità pubblicati negli ultimi anni.

## Contenuti

- Presentazione dell'azienda Ferrero
- Quadro di sostenibilità suddiviso in quattro pilastri
- Principali indicatori e risultati
- Collegamenti ai rapporti di sostenibilità ufficiali
- Layout responsive per la visualizzazione su dispositivi di diverse dimensioni

## Tecnologie utilizzate

- HTML
- CSS

## Struttura

La pagina è realizzata utilizzando un unico documento HTML con CSS integrato. La struttura è organizzata in sezioni indipendenti, collegate tra loro attraverso una barra di navigazione interna.

Particolare attenzione è stata dedicata alla leggibilità dei contenuti, alla gerarchia visiva delle informazioni e all'adattamento della pagina a schermi di dimensioni differenti.
